# 奶蛙开发说明

## 构建

Windows 原生 C# / WinForms 客户端，使用 .NET Framework 4.x 和系统 Win32 API，无第三方运行时依赖。当前使用本机 .NET Framework 4.8 编译器，兼容 C# 5。

在 Naiwa 文件夹执行：

```powershell
& .\build.ps1
```

脚本把 assets 中的角色 PNG 与图标嵌入「奶蛙.exe」。不用下载包或联网还原依赖。

## 源文件

- Core.cs：设置 JSON、原子写入与备份恢复、UTC 计时、边界计算。
- Native.cs：每像素透明窗口、非激活显示、鼠标穿透、全屏检测。
- Visuals.cs：资源加载、姿态过渡、呼吸与回弹、提示气泡、专注进度。
- PetForm.cs：事件优先级、拖动、托盘与菜单、全屏/锁定/电源/显示器事件。
- Dialogs.cs：设置与自定义时长面板。
- Program.cs：单实例启动与恢复、异常记录。
- Tests.cs：计时/设置回归、原生窗口集成、界面渲染和性能采样。
- AssetPack.cs：构建时图集切分与基准对齐，不参与运行程序编译。

动画动作由立即替换的当前状态驱动，没有累积播放队列。拖动优先于随机动作；隐藏时停止绘图；专注结束事件保留到可见时再消费，避免丢提示与重复提示。

1.0.1：Wake 在调用 Tick 前取消旧动作和结束回调，防止延迟的睡觉结束回调把刚叫醒的角色再次隐藏。显式启动会恢复已保存的睡眠/隐藏状态，保留其它偏好和计时；托盘单击、双击、菜单及单实例消息均调用同一唤醒流程。

1.0.2：睡觉成为持续可见的桌面姿态，不再执行隐藏回调。绘制角色右上方的 Z，减少动作时静止显示。打盹期间关闭随机动作与提醒，专注完成通知保留到叫醒；单击身体可叫醒。全屏避让、锁屏和主动隐藏仍沿用原有规则。

1.0.3：角色正式命名为「奶蛙」，统一更新窗口、菜单、托盘、设置面板、提示、程序元数据、文件名与产品资料。程序目录改为 Naiwa，迁移原有 data 文件夹以保留用户设置和专注记录。

1.0.4：点击肚子改为播放用户提供的 12 帧捧腹大笑素材，以 12 帧/秒播放约两秒后恢复待机。所有帧采用统一缩放和脚底基准；点击重新开始当前动作，不累积队列；「减少动作」时显示静态大笑姿态。素材及处理说明见 source/捧腹大笑素材说明.md。

## 验证

```powershell
$testProcess = Start-Process -FilePath '.\奶蛙.exe' -ArgumentList '--self-test', 'C:\path\to\test-output' -PassThru -WindowStyle Hidden
$testProcess.WaitForExit()
$testProcess.ExitCode
```

退出码 0 为通过。输出目录生成验证报告、设置面板 PNG、角色姿态 PNG、result.txt 和隔离的设置测试数据。测试会短暂显示自有测试窗口与一个全屏测试窗口，不会主动锁定电脑或读取其它应用内容。

仅跑睡眠问题回归可以将 `--self-test` 改为 `--sleep-regression`。测试故意阻塞 UI 线程 1550 毫秒，让睡觉动作已到期、计时器尚未执行，再通过叫出、原生唤醒消息和托盘通知事件恢复。托盘通知使用框架事件入口触发，菜单使用实际菜单项点击；没有模拟系统托盘图标的物理鼠标点击。

性能数字来自同一测试进程的 20 秒待机采样，包含测试夹具的内存开销。CPU 同时给出单核与整机归一口径。测试不会宣称已完成两小时稳定性或所有硬件配置的验收。

## 角色资源

基础姿态由内置 imagegen 根据用户参考图生成。提示词保存于 source/角色资源提示词.txt。捧腹大笑另使用用户提供的 12 帧序列，经内置 imagegen 去白底后导入。AssetPack 从规则图集切分主体区域并对齐脚底；导入器保留角色连通区域及抗锯齿边缘，清理背景碎点，所有大笑帧使用同一比例。运行资源全部嵌入程序。

后续可替换为艺术家制作的透明逐帧动画，或接入骨骼动画。优先改进眨眼、手臂拍肚和走路的连续性，再增加配饰与低频彩蛋。

## 原生 API 依据

- [UpdateLayeredWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow)：更新透明窗口内容。
- [Layered Windows](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows)：alpha 为 0 的区域可穿透，WS_EX_TRANSPARENT 支持整窗穿透。
- [Windows Forms Form 源码](https://source.dot.net/System.Windows.Forms/System/Windows/Forms/Form.cs.html)：显示与焦点行为参考；本机集成测试验证 .NET Framework 实际行为。

框架的 TopMost 属性会在显示流程里触发焦点逻辑。本实现改用原生置顶标志与 SWP_NOACTIVATE，并关闭控件可选择状态，防止显示、鼠标点击与唤醒时获取输入焦点。
