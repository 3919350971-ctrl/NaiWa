# 奶蛙 1.0.4

住在桌面上的慢半拍朋友。

## 开始使用

双击「奶蛙.exe」。程序是 Windows 便携版，无需安装 Python、Node.js 或开发工具。解压压缩包后再启动，不要直接在压缩包里运行。

角色图片已嵌入程序，日常使用只需要 exe。assets 与 source 文件夹供修改和重新编译使用。

默认出现在桌面右下角。程序默认静音、不散步、不主动提醒、不设置开机启动。首次运行会显示一次操作提示。

## 怎么逗它

| 操作 | 反应 |
| --- | --- |
| 单击头部 | 眯眼、歪头 |
| 单击肚皮或身体 | 捧腹大笑约 2 秒，随后恢复待机 |
| 按住身体拖动 | 提起；放开时轻轻回弹，保留新位置 |
| 右键角色 | 打开专注、睡觉、设置等菜单 |
| 单击或双击系统托盘里的奶蛙 | 叫出角色，并恢复鼠标互动 |

透明空白区域不拦截鼠标。角色不抢键盘焦点。托盘图标可能收在任务栏右侧的「显示隐藏图标」箭头里。

## 陪你专注

右键 → 陪我专注 → 25 分钟、50 分钟，或 1–240 分钟的自定义时长。

奶蛙坐下来，脚边显示小计时条。点击角色或右键可查看、暂停、继续或结束本次专注。专注时停止随机动作、散步和休息提醒。

结束后只显示一次休息提示。睡眠或重启后按照原定结束时间恢复；打盹期间到期会等叫醒后再提示。暂停状态下不会消耗剩余时间。

## 睡觉、隐藏和全屏

- 回窝睡觉：留在原位坐下打盹，头部右上方显示轻轻飘动的 Z。睡觉时停止眨眼、散步与休息提醒；已有专注计时仍会继续。开启「减少动作」后 Z 静止显示。
- 暂时隐藏：立即收起，托盘图标仍在。
- 全屏应用：默认自动隐藏，退出全屏后恢复；计时继续。
- 退出奶蛙：结束程序并保存设置。重新双击 exe 可以启动。

再次启动已运行的程序会叫出已有的奶蛙，不会创建第二只。

睡觉后单击角色身体即可叫醒，也可以单击/双击托盘图标，或右键角色/托盘 →「叫醒奶蛙」。重新双击 exe 也能叫醒。即使上次退出时在睡觉，本次启动也会自动叫醒，保留角色尺寸、位置和专注计时。

## 设置

支持角色高度 96–240 像素、全屏避让、桌面底边小步散步、每小时休息提醒、减少动作和鼠标穿透。沿底边散步只在角色位于桌面底部附近时发生；默认关闭。

鼠标穿透开启后，角色本身无法点击；单击托盘图标可以恢复。找不到角色时可从托盘菜单选择「放回桌面右下角」。

设置保存在程序旁边的 `data/settings.json`，自动保留一份 `.bak` 备份。请将 exe 放在你可写入的文件夹。需要恢复出厂设置时，先退出程序，再移走 data 文件夹。

## 本地与隐私

客户端不联网，不需要注册，不使用 AI 服务，不读取屏幕图像、文件内容、键盘输入、麦克风或摄像头。全屏避让只检查前台窗口的边界和所属进程。数据仅用于保存角色位置、偏好和专注计时。

## 版本说明

本版包含 12 个角色姿态，并用呼吸、回弹、轻晃与短过渡形成动画。它是可以使用的第一版，尚未制作完整骨骼动画、连续行走序列、成长配饰或 AI 对话。

点击肚子使用 12 帧捧腹大笑动画，持续约两秒；连续点击会重新开始大笑，结束后回到待机。开启「减少动作」时只显示静态大笑姿态。

已在当前 Windows 11 电脑测试。两小时连续运行、真实锁屏/休眠、物理显示器拔插与全部缩放比例组合还需长期使用验收；自动测试覆盖了对应的事件逻辑与边界处理。
